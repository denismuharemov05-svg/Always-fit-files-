# Always Fit — Android starter (първа тестова версия)

Този проект опакова наличния HTML прототип във Android приложение чрез Capacitor. Не е публикувано в Google Play и APK-то, което се изгражда от GitHub Actions, е **debug/test APK**, а не подписан release за магазина.

## Съдържание
- `www/index.html` — основният прототип (FOUNDATION 0.3)
- `www/scanner.html` — отделна експериментална страница за камера/броене на клекове
- `capacitor.config.json` — Android идентификатор и папка с уеб съдържанието
- `.github/workflows/build-apk.yml` — автоматично изграждане на APK в GitHub Actions

## Важно преди тестване
- Екранът „Скенер“ в основния прототип е DEMO и не анализира истинска поза.
- `scanner.html` е отделен експеримент. Камерата и MediaPipe може да изискват интернет, разрешения и допълнителни корекции в Android WebView.
- Прогресът в основния HTML се съхранява локално на устройството чрез localStorage; не се синхронизира между устройства.
- Преди публикуване в Google Play са нужни release signing, икони, политика за поверителност и проверка на всички функции.

## Изграждане само с телефон чрез GitHub Actions
1. Изтегли и разархивирай ZIP файла на телефона.
2. В GitHub създай нов **празен** repository с име `always-fit-android`.
3. Качи съдържанието на разархивираната папка в корена на repository. Увери се, че качваш и скритата папка `.github/workflows/` (някои файлови браузъри я скриват).
4. Направи commit към клона `main`.
5. Отвори таба **Actions** в repository и избери **Build Always Fit Android APK**. Ако workflow не се вижда, провери дали файлът `.github/workflows/build-apk.yml` е качен правилно.
6. Натисни **Run workflow** или изчакай автоматичното изпълнение след push.
7. Когато изпълнението стане зелено, отвори го и намери **Artifacts** → `always-fit-debug-apk`. Изтегли ZIP артефакта и го разархивирай.
8. Отвори `app-debug.apk` на телефона и разреши инсталиране от този източник, ако Android поиска. Инсталирай само APK от собственото ти repository/build.

## Ако качването на папки от телефона е трудно
Използвай GitHub Codespaces в браузър, ако е наличен за акаунта ти, или друг доверен облачен редактор. Не споделяй пароли или токени. Не е необходимо да публикуваш repository публично — private repository е за предпочитане.
